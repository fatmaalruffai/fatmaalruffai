## Featured projects

### Virtual Robotics Lab
A 3D build-and-code lab: learners choose an animal robot (frog, turtle, crocodile, parrot), assemble it step by step, program its motor with blocks and complete challenges. Includes a teacher page for each project.
`HTML` `CSS` `JavaScript` `three.js` · [Live demo](https://fatmaalruffai.github.io/robotics-lab/) · [Repository](https://github.com/fatmaalruffai/robotics-lab)

### Joints Lab
Build a robotic joint, wire a servo, explore angles in degrees and radians, assemble an Arduino program from blocks and take on a humanoid-arm challenge.
`HTML` `CSS` `JavaScript` `three.js` `Arduino (C++) code builder` · [Live demo](https://fatmaalruffai.github.io/joints-lab/) · [Repository](https://github.com/fatmaalruffai/joints-lab)

### Plants and Pollinators Lab
Connects biology and robotics: learners study how bees pollinate flowers, then build, connect, program and test a moving pollinator model, and reflect on their design.
`HTML` `CSS` `JavaScript` `three.js` · [Live demo](https://fatmaalruffai.github.io/pollinators-lab/) · [Repository](https://github.com/fatmaalruffai/pollinators-lab)

### Build a Mixer Lab
Design a motorised mixer: build it, add a controller and potentiometer, program the speed and test the result.
`HTML` `CSS` `JavaScript` · [Live demo](https://fatmaalruffai.github.io/mixer-lab/) · [Repository](https://github.com/fatmaalruffai/mixer-lab)

### Battery Builder · Little Lever Builder
Two short home-learning missions for younger learners: build series and parallel circuits to power toys, and build and test the three classes of lever. Each ends with a printable certificate.
`HTML` `CSS` `JavaScript` · [Battery Builder](https://fatmaalruffai.github.io/battery-builder/) · [Little Lever Builder](https://fatmaalruffai.github.io/little-lever-builder/)
